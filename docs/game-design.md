### ゲームループ

1. **メダル投入** — 投入したメダルは放物線を描いて奥のデッキに着地し、往復するプッシャーに押される。前縁から落ちたメダルは 1 枚 = 1 クレジットで払い出し。
   投げ上げ初速は**重力から逆算**している（`MedalSpawner.throwCoin`）。固定値にしていた頃、
   重力を -9.81 → -15.5 に上げた際に飛距離が z=-2.1 → -0.6 まで落ち、投入メダルが奥のデッキまで
   届かなくなった。着地点と滞空時間を与えて初速を解く形にしてあるので、重力を変えても崩れない。
2. **メダルの見た目** — 素材は**洋銀（ニッケルシルバー）**。フチには**ギザ（ミリング）**、表面には
   立ち上げリム・ビーズリング・星の打刻・アーチ状の刻印を、アルベド／バンプ／ラフネスの
   3 枚が一致する形で持たせている（`medalTexture.ts`）。円柱の 3 マテリアルグループを使い、
   **側面だけギザ専用マテリアル**にしているのが「本物の硬貨に見えるか」の分かれ目。
   ※ metalness=1 では `color` × `map` がそのまま反射色になるため、`color` は白。両方で色を付けると二重に暗くなる。
3. **横穴（ハウスエッジ）** — 下段フィールドは手前に向かって狭まる台形で、左右の**壁**に高さ 0.46 の開口がある（z 1.0〜3.1）。端に寄ったメダルはここから抜け、落下しながら床付近で消える（一部はジャックポットプールに繰り入れ）。
4. **ダイス（ミニキューブ）** — メダルを 40 枚投入するごとにホッパーから 1 個排出される、白いサイコロ型の小キューブ。一辺 0.52 に対して横穴の開口は 0.46 しかないため**物理的に抜けられず**、必ず前面に到達する（不可視ガイドのような仕掛けは使っていない）。メダルと同じように押して**前縁から落とすとすごろくが 1 手進む**。
5. **すごろく（奥のモニター）** — 左のトレイで**実物理のサイコロ**を振り、出た目そのままコマが進む。ゴールまで 50 マスの一本道で、モニターには現在地から先 12 マス分だけを表示（全体像は上部のプログレスバー）。ストックされたダイスの個数も併せて表示。
   盤面は**全ての段が左→右**で、段と段のあいだは**マスを置かない S 字の連絡路**（破線）でつないでいる。
   一段おきに向きが反転する本来のつづら折りだと「どっちが前か」を段ごとに読み直すことになるので、
   進行方向は常に画面右向きに固定し、戻る動きは連絡路にだけ担わせている。
   - **なにもなしマス** — 過半数。何かが起きたときに効くよう、意図的に「間」を置いている
   - **メダルマス** → 一定枚数を物理排出（クレジット直入ではなく、押して回収する）
   - **JP アップマス** → 累積ジャックポットプールに加算
   - **ダイス勝負マス** → その場でもう一度振り、出目に応じた配当（1→3枚 … 6→21枚）
   - **特殊マス** → ダイス 2 個（次の手は 2 個振って合計）/ 出目えらび（次の手は 1〜6 を選択）/ 配当 2 倍 / 数マス進む / 数マス戻る
   - **GOAL（50 マス目）** → 抽選ボウル（JPC）へ。到達で FEVER 突入（盤面配当 ×2）、コマは 0 に戻り周回数が 1 増える
6. **抽選ボウル（JPC）** — 筐体**右側の台形壁の外面に直付け**された漏斗状のボウル。ボールが放たれ、外周を回りながら少しずつ内側へ落ちていき、最後に中央の穴へ吸い込まれる。
   サイコロトレイ（左壁）とボウル（右壁）は、以前は床から生えた独立の台に載っていた。
   奥まっていて見えづらいうえ、「別の機械が隣に置いてある」ようにしか見えなかったため、
   **台形壁の外面に、壁のヨー角に合わせて直付け**し、サイズも 3/4 に落とした。
   取り付け位置は `layout.ts` の `wallMount(side, z)` が台形形状から導出する——
   `x` は書かない。台形を切り直したときに手書きの数値だけ取り残されるのを防ぐため。
   ボールが回っているあいだ画面左でルーレットが回り続けており、**ボールが穴に消えた瞬間に指していたマス目が当たり**。1/16 の JACKPOT を引けば累積ジャックポット全額。
   結果は一切仕込んでおらず、物理が決めるのは「いつ落ちるか」だけ。その「いつ」が「何が当たるか」を決めます。
7. **チンチロ（獲得メダル増加チャレンジ）** — 抽選ボウルの結果は**そのまま払い出されず**、賭け金としてチンチロに載る。トレイに実物理のサイコロを 3 個投げ、役で倍率が決まる。
   - ピンゾロ ×5 / ゾロ目 ×3 / シゴロ ×2.5 / 目 1〜6 ×1.1〜2.0 / **ヒフミ ×0.5（減る）**
   - 目なしは最大 3 投まで振り直し。3 投使い切っても役が出なければ ×1（賭け金がそのまま通る）
   - 平均倍率は約 ×1.5。だからボウルの配当表そのものは低めに置いてあり、**ボウルが見せているのは配当ではなく賭け金**
8. **プレイヤー進行** — 獲得クレジットで EXP が貯まりレベル/ランクアップ（ビギナー→…→レジェンド）。盤面の進行状況も含めて localStorage に自動セーブ。

### メダル収支

払い出し率は **約 90%**。`test/draintest.mjs` で横穴の排出率を実測し、そこから逆算しています。

```
payback = (1 − s)(1 + w) + jp
   s  … 横穴から抜けるメダルの割合（実測 29.3% ± 1.9%、n=2331）
   w  … 投入1枚あたりの排出枚数（盤面 + ボウル×チンチロ）
   jp … 投入1枚あたりのジャックポット払い出し
```

現行値: s=29.3%, w=0.130, jp=0.104 → **90.2%**

| チャネル | 投入に対する還元 |
| --- | --- |
| 前面受け皿からの払い出し | 約 80%（うち投入分の 70.7% は素通り） |
| ジャックポット（長期平均） | 約 10% |

**ドレイン率 s がすべての上限を決めます。** 投入の (1−s) はどうやっても前面へ戻るので、
s=29.3% なら**盤面が 1 枚も払わなくても 71% は返ってしまう**。盤面・ボウル・JP の 3 つ合わせて
残り 20 ポイントを取り合っているだけ、という構造です。

そのため調整レバーには強弱があります:

| レバー | 効き | 備考 |
| --- | --- | --- |
| `LAYOUT.sideHole`（穴の長さ・高さ） | **最強** | s そのもの。高さは**ミニキューブの一辺 0.52 未満**が絶対条件（0.46 = 余裕 0.06） |
| `LAYOUT.medalsPerBall` | **強** | 1 手の「値段」を変える。**払う額はそのままで払う頻度だけ下がる**ので、1 回の当たりが大きくなる |
| `Board.PAYOUT_SCALE` | 弱 | 0.50→0.30 に落としても payback は 4 ポイントしか動かず、盤面がケチに見えるだけだった |
| `Economy.JP_PER_*` / JP マス | 弱 | jp 項のみ |

> メダルを大きく・厚くした（r 0.30→0.32 / t 0.08→0.105）ときに s が 48%→24% まで落ち、
> payback が 110% を超えて**胴元が負ける**状態になりました。太いコインはテーパーに押されて
> 壁から遠ざかるためです。横穴を伸ばして（z0 1.35→1.0）高くして（0.42→0.46）29.3% まで戻し、
> `medalsPerBall` 25→40 で 90% に着地させています。
> **メダルの寸法を触ったら必ず `draintest` を回し直してください。**
